# HandoffGraph v0.8.0-beta.1

This is prepared release-note copy. Its presence in the repository is not
evidence that the tag or GitHub prerelease has been published.

HandoffGraph v0.8.0-beta.1 expands the local-first continuity and
session-debugging CLI with a guarded Hosted Basic preview. Local capture and
the SQLite event spine remain the source of truth; hosted sync is explicit,
redaction-gated, tenant-scoped, and quota-aware.

## Highlights

- Deterministic append-only event, graph, trace, checkpoint, and handoff
  projections with crash/reopen recovery and exact-envelope idempotency.
- Native Codex, Claude Code, and Pi transcript normalization with provider
  provenance, deterministic session IDs, fail-closed redaction, and six-pair
  real-client continuation evidence.
- Hosted Basic account, device, workstream, event-batch, plan, and health
  routes on Cloudflare Workers with workspace isolation, hashed browser/device
  credentials, CSRF protection, and one-time device-token issuance.
- Transactional monthly, batch, active-device, and lifetime-device-issuance
  quotas. Denials return structured bounded retry guidance without blocking
  local capture or creating hot-loop retries.
- Explicit hosted sync with a complete content-free redaction preview,
  required first-upload acceptance, deterministic batches, crash-safe resume,
  and replay-safe idempotency.
- Owner-confirmed account deletion with D1/R2 cleanup, WorkOS provider
  deletion, retry/grace-sweep handling, durable tombstones, and post-deletion
  authentication fences.
- Strict hosted security boundaries: deny-by-default CSP, no-store auth
  responses, deployment identity headers, maintenance fencing, and optional
  Turnstile form plus server-side Siteverify enforcement when configured.
- Reproducible cross-platform Go archives with SHA-256 checksums and a
  release workflow that validates the annotated tag, assets, clean module
  installs, and immutable publication before promotion.

## Compatibility and installation

- Go 1.25 or newer is required when installing from source.
- The supported module path is
  `github.com/handoffgraph/handoffgraph/cmd/handoffgraph`.
- The release matrix covers Linux, macOS, and Windows on amd64 and arm64.
  Verify any downloaded archive against the same release's `checksums.txt`
  before installation.
- No stable public release exists. Test this beta with a copied or fresh
  `HFG_DATA_DIR` before relying on it for durable workflows.

## Hosted preview and deployment state

- The repository contains 22 ordered D1 migrations. The complete chain is
  applied and verified on isolated staging; production migration and public
  signup are intentionally launch gates.
- Hosted Basic keeps only deletion-compatible D1/R2 bindings. Advanced and
  Enterprise routes remain disabled unless separately licensed and enabled.
- The current staging Worker is source-pinned and preflighted anonymously.
  WorkOS credentials, Turnstile keys, reviewed WAF/rate controls, real
  authenticated browser/CLI lifecycle, production cutover, and Vercel
  retirement are not claims of this prerelease note.

## Known gaps

- The canonical `github.com/handoffgraph/handoffgraph` repository and the
  public immutable GitHub release require the owner-controlled repository
  transfer/create gate.
- Public production acceptance on `handoffgraph.dev` remains pending the
  documented WorkOS, Turnstile/WAF, DNS, migration, authenticated lifecycle,
  and deletion gates.
- Provider hook installation remains fail-closed and never overwrites
  conflicting user-owned configuration.
- This is beta software. Keep native provider transcripts as the source of
  truth until imported events and continuation flows are verified for the
  target environment.

## Verification

The release workflow rebuilds and tests the Go, web, platform, staging, and
landing surfaces from the annotated tag; builds six GoReleaser v2.17.1
archives; verifies their checksums; proves two clean canonical module
installs; and publishes only after the exact assets and immutable-release
contract pass.
