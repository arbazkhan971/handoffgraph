not configured, the application has no Turnstile Siteverify integration yet,
and the current Cloudflare OAuth token cannot inspect or mutate Turnstile/WAF
state. The canonical GitHub namespace, prerelease tag, production migrations,
DNS/custom-domain cutover, authenticated two-tenant lifecycle, deletion proof,
and Vercel retirement remain outside this acceptance record.
