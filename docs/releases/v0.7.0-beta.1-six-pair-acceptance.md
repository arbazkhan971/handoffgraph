## Regression found during acceptance

Claude Code `2.1.227` sent standard MCP client metadata fields that the server
previously rejected as unknown. Candidate commit `ca4a9b8` accepts the standard
`description`, `websiteUrl`, and `icons` client-info fields while retaining
strict rejection of unknown tool arguments. The final six-pair run above was
performed only after rebuilding from that committed fix.
