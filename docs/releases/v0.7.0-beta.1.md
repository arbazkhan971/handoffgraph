# HandoffGraph v0.7.0-beta.1

This is prepared release-note copy. Its presence in the repository is not
evidence that the tag or GitHub prerelease has been published.

HandoffGraph v0.7.0-beta.1 is scoped as the project's first public
prerelease: a local-first continuity and session-debugging CLI for Codex,
Claude Code, and Pi, plus an explicitly gated Hosted Basic preview.

## Highlights

- Append-only SQLite event spine with deterministic graph/trace reducers,
  crash/reopen recovery, exact-envelope idempotency, and atomic native-session
  imports.
- Merge-safe, fail-closed Codex, Claude Code, and Pi capture integration;
  provider-native transcript detection, UTF-8-safe visibly marked inline
  truncation, normalization, and resume/fork specs.
- Verified checkpoint and handoff lifecycle through the 12-tool local MCP
  server, including bounded previews, repository-drift checks, and machine
  acknowledgement.
- Embedded local Session Debugger UI, deterministic detection pack, OTLP JSON
  and protobuf ingestion, scores, datasets, prompts, and verification records.
- Explicit-only hosted sync with fail-closed redaction preview/acceptance,
  deterministic idempotency keys, crash-safe cursor advancement, and
  quota-aware backpressure. Monthly 429s surface bounded wait guidance;
  batch/lifetime denials do not trigger an unchanged hot-loop retry, and the
  next explicit sync replays the exact durable pending request.

## Compatibility and installation

- Go 1.25 or newer is required when installing from source.
- The supported module path is
  `github.com/handoffgraph/handoffgraph/cmd/handoffgraph`.
- The release matrix covers Linux, macOS, and Windows on amd64 and arm64.
  Verify any downloaded archive with the same release's `checksums.txt` before
  installation.
- No earlier public stable release exists, so there is no in-place upgrade
  baseline. Test the prerelease with a copied or fresh `HFG_DATA_DIR` before
  relying on it for durable workflows.

## Hosted preview and migrations

- The repository contains 22 ordered D1 migrations. They have been applied to
  the isolated signup-closed staging database only.
- Before this first public tag, migrations 0003, 0004, and 0008 received a
  syntax-only parenthesization repair required by the remote D1 parser. The
  full fresh chain and the existing isolated staging ledger are release gates;
  no public production database predates this baseline.
- Hosted production, public signup, WorkOS authentication, Turnstile/WAF
  controls, and the production D1 migration are not part of the planned
  prerelease's live surface.
- The repository's Hosted Basic code path does include structured quota 429s,
  monthly `Retry-After`, and exact manual replay semantics. That code-level
  completion is not a claim that the public production service is live.
- Hosted Advanced and Enterprise surfaces remain disabled; the planned release
  does not certify them for production activation.

## Known gaps

- Public production acceptance on `handoffgraph.dev` is still pending the
  documented owner-controlled identity, abuse-control, DNS, and deletion
  gates.
- Provider hook configuration is intentionally fail-closed. Existing
  conflicting managed state must be reviewed manually; the installer never
  overwrites user-owned configuration.
- This is beta software. Keep native provider transcripts as the source of
  truth until the imported event log and continuation flow have been verified
  for your environment.

## Verification

The six directed native-client continuation pairs were exercised against real
Codex, Claude Code, and Pi transcripts and acknowledged by the destination
clients through MCP. The sanitized evidence is recorded in
[`v0.7.0-beta.1-six-pair-acceptance.md`](v0.7.0-beta.1-six-pair-acceptance.md).

The release workflow rebuilds and tests the Go, web, platform, staging, and
landing surfaces from the annotated tag, builds six archives with GoReleaser
v2.17.1, and publishes SHA-256 checksums only after every validation job
passes.
