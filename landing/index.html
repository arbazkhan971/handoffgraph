Quickstart

Four commands. The second agent starts with everything the first one proved.

$ handoffgraph install # capture events from claude + codex, idempotently
$ handoffgraph checkpoint --workstream ws_01JZ… # freeze an evidence-backed state
$ handoffgraph continue --to codex # launch codex seeded with that checkpoint
$ handoffgraph open # inspect the session debugger while it runs

The workstream graph

Every session becomes a node and every claim becomes evidence. A checkpoint carries the graph forward, so the next agent inherits work — not vibes.

Evidence nodes are captured from real execution and linked into the checkpoint — nothing in the handoff is asserted without a reference.

Every claim has a level

Provenance is preserved end-to-end. An inferred summary can never masquerade as an observed passing test.

OBSERVED

Captured from real execution: files with content hashes, commands with exit codes, test runs, git state.

DECLARED

Stated by a human or an agent: objectives, constraints, decisions, next actions.

INFERRED

Derived by analysis: summaries, scores, model output — always labelled, never shown as fact.

Built for the handoff, not the dashboard

Verified handoffs

Cross-agent continuity

Claude Code → Codex → Pi. Checkpoints travel with the work.

Fail-closed redaction

If a deny pattern can’t be applied, export stops — secrets never leak by warning.

Apache-2.0

Open source, inspectable, self-hostable. No lock-in, ever.

Privacy is the architecture

  • Everything runs locally: events, the workstream graph, and checkpoints live on your disk.
  • Nothing is uploaded — no telemetry, no cookies, no trackers, no third-party requests on this page.
  • Redaction is fail-closed: a broken deny pattern blocks export instead of leaking secrets.
  • Provenance is preserved: inferred summaries are never rendered as observed facts.
  • The waitlist form posts one JSON object to our own worker; if that fails, your answers stay in your browser.
