Evidence, not vibes

Every claim keeps its label.

An inference can be useful. It just cannot masquerade as a captured fact. HandoffGraph preserves provenance through checkpoint and acceptance.

The checkpoint builder is deterministic and model-free. Inferred fields remain visibly inferred; redaction failure stops export.
File changes, commands, test results, errors, and recorded decisions point back to source event IDs such as evt_01J2…0014. Repository state is captured separately as checkpoint metadata.
Objectives, constraints, decisions, and next actions remain attributed instead of being promoted to observed truth.
Summaries and analytical output stay explicitly labelled, so the next agent can distinguish interpretation from execution evidence.

Common questions

What this is—and isn’t.

Is HandoffGraph another agent observability platform?

It includes local trace debugging, but its distinctive job is continuity: selecting evidence from captured work, packaging it into a bounded checkpoint, checking repository drift, and carrying acknowledgement into the next agent session.

Does it launch Claude, Codex, or Pi for me?

No. HandoffGraph prints a shell-quoted native invocation for you to review and run. Preview mode performs no handoff write.

Does captured work leave my machine?

Local Core stores events and checkpoints on disk in local SQLite and never requires an account. Hosted Basic is a separate, opt-in limited beta: only batches sent with a scoped hosted device token reach the hosted API, and redaction failures are rejected.

What happens when Hosted Basic reaches a limit?

Cloud sync pauses before accepting more hosted data. Local capture, checkpoints, debugging, and continuation keep working, and there is no automatic overage charge.

What does Hosted Basic sync?

The beta contract accepts validated event envelopes within its hard count and byte caps, and rejects events marked with a redaction failure. Envelopes are preserved rather than reduced to a smaller metadata projection.

Can a summary be presented as a passing test?

No. Provenance is preserved as OBSERVED, DECLARED, or INFERRED, and checkpoint claims retain evidence references where the event contract provides them.
